# Linux 基礎指令與終端機工具指南

這份指南涵蓋了 Linux 系統中最實用的基礎指令，並詳細整理了 `htop`、`tree` 以及終端機編輯器（`nano` 與 `vim` / `nvim`）的使用方式。無論是在撰寫 C++ 演算法、透過 SSH 管理系統與專案，還是在 Linux 環境中進行除錯與資安挑戰，這些指令都能大幅提升終端機的操作效率。

## 2. 系統與資源監控：`htop`

`htop` 是一個互動式的系統行程監控工具，比傳統的 `top` 指令更直觀，支援色彩顯示、滑鼠點擊以及完整的行程樹狀結構。非常適合用來監控編譯大型專案或執行高負載運算時的資源消耗。

### 常用操作與快捷鍵

- **F1 / h** : 顯示幫助選單。
- **F2 / S** : 設定 (Setup)，可自訂頂部儀表板要顯示的資訊（如 CPU 各核心使用率、記憶體狀態）。
- **F3 / /** : 搜尋行程 (Search)，快速定位特定程式。
- \*\*F4 / \*\* : 過濾行程 (Filter)，只顯示包含特定關鍵字的行程（例如過濾出所有 `python` 或 `java` 行程）。
- **F5 / t** : 切換樹狀視圖 (Tree view)，顯示父子行程（Process Tree）的層級關係。
- **F9 / k** : 終止行程 (Kill)，選擇卡死的行程後按 F9，然後按 Enter 發送 `SIGTERM` 或 `SIGKILL` 訊號。
- **F10 / q** : 離開 `htop`。

## 3. 專案結構視覺化：`tree`

`tree` 指令會以樹狀圖的方式列出目錄及其下的所有檔案與子目錄，在檢視專案架構、逆向工程解包後的資料夾或整理環境結構時非常實用。

### 常見實用參數

- `tree` : 列出當前目錄下的所有結構。
- `tree -L 2` : 限制顯示的層級（Level），例如只顯示往下 2 層的目錄。
- `tree -a` : 顯示所有檔案，包含隱藏檔 (以 `.` 開頭的檔案)。
- `tree -d` : 只顯示目錄結構，隱藏所有一般檔案。
- `tree -I "node_modules|.git"` : 忽略 (Ignore) 特定資料夾，保持輸出乾淨。

## 4. 終端機編輯器指南 (`nano` 與 `vim` / `nvim`)

在純文字介面下，`nano` 與 `vim` 是最核心的編輯工具。（備註：「nanovim」通常是指這兩種編輯器的統稱與比較，或是現代化的 Neovim，簡稱 `nvim`）。

### 🟢 Nano (輕量、直觀、好上手)

`nano` 是一個所見即所得的編輯器，底部會顯示所有常用的快捷鍵提示（`^` 代表 `Ctrl` 鍵）。適合快速修改簡單的設定檔。

- **開啟檔案**：`nano config.json`
- **儲存檔案**：按 `Ctrl + O` (Write Out)，然後按 `Enter` 確認檔名。
- **離開編輯器**：按 `Ctrl + X` (Exit)。若有未儲存變更，會詢問是否儲存 (按 `Y` 確認)。
- **搜尋文字**：按 `Ctrl + W` (Where Is)，輸入關鍵字後按 `Enter`。

### 🔴 Vim / Neovim (高效、全鍵盤操作、功能強大)

`vim`（以及其現代分支 Neovim）是強大的模態編輯器。它的核心概念是「模式切換」，讓雙手不需要離開主鍵盤區即可完成所有編輯與游標移動。

**三大基本模式：**

1. **普通模式 (Normal Mode)**：開啟檔案時的預設模式。按鍵會被視為指令（移動、複製、刪除），無法直接打字。
2. **插入模式 (Insert Mode)**：用來輸入文字。在普通模式下按 `i` 進入，左下角會顯示 `-- INSERT --`。
3. **命令列模式 (Command-line Mode)**：用來儲存、離開或全域替換。在普通模式下按 `:` 進入。

**Vim 基礎編輯指令：**

- **開始編輯**：普通模式下按 `i` 進入插入模式。
- **退出編輯**：按 `Esc` 鍵回到普通模式。
- **儲存檔案並離開**：按 `Esc` 進入普通模式，輸入 `:wq` 後按 `Enter`。
- **強制離開不儲存**：按 `Esc` 進入普通模式，輸入 `:q!` 後按 `Enter`。
- **快速游標移動** (普通模式下)：
  - `h` (左)、`j` (下)、`k` (上)、`l` (右)
  - `gg` (跳至檔首)、`G` (跳至檔尾)
- **快速刪除/複製** (普通模式下)：
  - `dd` : 剪下（刪除）當前整行。
  - `yy` : 複製當前整行。
  - `p` : 貼上。

> **💡 關於 Neovim (nvim)：**
> Neovim 是 Vim 的現代化重構版本，完全相容 Vim 的鍵位操作，但擁有更好的效能與強大的 Lua 擴充生態。如果您打算長期在終端機內寫 Code，非常推薦嘗試學習並配置 Neovim。

## Byobu 基礎教學

Byobu 是一個強大的文字介面視窗管理員（底層通常是 tmux），它可以讓你在一個終端機畫面中開啟多個分頁、分割視窗，最重要的是：即使網路斷線或不小心關閉終端機，裡面的程式仍會繼續在背景執行，下次連線時可以無縫接軌。

## 📌 啟動與基本設定

* **啟動 Byobu**：在終端機輸入 `byobu` 即可進入。
* **設定登入時自動啟動**：輸入 `byobu-enable`。以後每次 SSH 登入伺服器都會自動進入 Byobu 環境。
* **取消自動啟動**：輸入 `byobu-disable`。
* **設定選單**：按下 `F9` 可以開啟設定選單，調整狀態列要顯示的資訊（如 CPU、記憶體、網路狀態等）。

## 📌 常用快捷鍵指南

Byobu 的操作主要依賴鍵盤的 `F1` ~ `F9` 鍵。

### 1. 視窗管理 (Window - 類似瀏覽器分頁)
* **F2**：建立一個新的視窗（底下狀態列會多出一個數字標籤）。
* **F3**：切換到上一個視窗 (往左切換)。
* **F4**：切換到下一個視窗 (往右切換)。
* **F8**：重新命名當前視窗，方便辨識（例如命名為 `server` 或 `vim`）。

### 2. 窗格分割 (Pane - 將同一個畫面切成好幾塊)
* **Shift + F2**：水平分割畫面（上下各一半）。
* **Ctrl + F2**：垂直分割畫面（左右各一半）。
* **Shift + F3** / **Shift + F4**：在分割的窗格之間切換。
* **Shift + F11**：將目前窗格放大到全螢幕 / 還原。

### 3. 實用功能與離開
* **F7**：進入「捲動與複製模式」。因為在 Byobu 內直接用滑鼠滾輪可能無效，按 `F7` 後可用上下鍵或 `PageUp`/`PageDown` 來查看歷史輸出，按 `Enter` 結束此模式。
* **F6**：斷開連線 (Detach)。這個動作非常重要！按下 `F6` 會退出 Byobu 畫面回到一般終端機，但在 Byobu 裡面跑的程式 (例如 Minecraft 伺服器、耗時的編譯或 Python 腳本) 不會中斷。下次再輸入 `byobu` 就會回到原本的畫面。
* **關閉視窗/窗格**：在該窗格輸入 `exit` 或按 `Ctrl + D`。如果這是最後一個窗格，就會完全退出並關閉該 Byobu 視窗。

## 軟體安裝指令

在 Debian/Ubuntu 系統環境下，請開啟終端機並輸入以下指令來安裝所有需要的工具：

```bash
# 1. 更新套件庫清單()
sudo apt update

# 2. 安裝 nano, vim, neovim, tree , byobu
sudo apt install nano
sudo apt install vim 
sudo apt install neovim
sudo apt install tree 
sudo apt install byobu -y
