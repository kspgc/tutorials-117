函式就是一個包含一段程式的集合
主要分為兩種，**無回傳值**和**有回傳值**的

# 無回傳值

無回傳值的主要目的通常是:
- 拆分結構
- 重複使用
- 增加可讀性

```python
def say_hi(name):
	print("hi",name)
	
say_hi("函毅哥哥")

# 輸出: hi 函毅哥哥
```

# 有回傳值

有回傳值的主要目的通常是:
- 拆解複雜的計算
- 重複使用
有一個很重要的概念
有回傳值的函式要被視為一個**值**

```python
def make_sauce(ingredient):
	result = f"{ingredient}醬"
	return result

print(make_sauce("函毅"))

# 輸出: 函毅醬
```

# 匿名函式

用於快速建立小函式

```python
add = lambda x, y: x + y
print(add(2, 3)) #輸出 5
```
