# Python 官網安裝

簡單來說，就是到python官網下載安裝包，按照步驟來。
這裡就不多提了，只講重點。

#### 1. 將PATH加入環境變數
這是**最重要的**一步驟，如果漏掉了，那你就每次都要先指定運行在安裝目錄才能跑`python`了，**一句話來說就是非常難用**。

先講講甚麼是環境變數，簡單來說，就是一個作用在電腦環境的變數，每當任何一個程式會帶入自己的變數指定例如`HOME`的位置，當運行時，就會從系統抓取到這的參數，並且填入使用。

當你在終端機輸入 `python` 時，Shell 會尋找這個命令。如果 Python 的安裝目錄已經加入 `PATH`，系統就能找到對應的 `python.exe`，因此你不需要輸入完整路徑。

#### 2. 版本選擇
到官網可以看到現在哪個版本有在維護，哪一個是預先發行，哪一個是穩定版。
如果在寫演算法，可以用最新的就好。但如果寫的是開發，那麼請確定所有依賴項都可運行在你要安裝的版本下。


# 從uv安裝

`uv` 不只是套件管理器，也可以管理 Python 版本、虛擬環境與整個專案。對於實際開發來說，我認為它比單純安裝一個全域 Python 更方便。

它可以處理：
- Python 版本
- 虛擬環境
- 套件 / dependencies
- 專案初始化
- lockfile
- 執行專案
- CLI tools

### 安裝
使用**PowerShell**安裝。
```bash
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

如果是Linux/Mac環境，在終端機中使用以下指令安裝。
```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

安裝程式通常會將 `uv` 加入 PATH；完成後重新開啟終端機，再輸入以下指令確認。
```bash
uv --version
```

### 使用方法

這時候你會發現，"欸不是 輸入`python --version`怎麼噴Error???"(如果沒有用官網的安裝包的話~)。
因為我們只有安裝 `uv`，但系統裡可能還沒有可用的 Python interpreter。這時候可以直接讓 `uv` 幫我們安裝 Python。

有兩種方式可以使用python。

#### 全域運行預設版本
現在有了`uv` 但還沒有Python，我們可以從`uv`中安裝Python最新版。
```bash
uv python install  # 最新版
uv python install 3.13  # 指定版本
```

也可以列出版本清單選擇版本
```bash
uv python list
```

如果你沒有把 Python 安裝到系統 PATH，或者你希望使用 uv 管理的 Python，就可以使用 `uv run`。
```bash
uv run filename.py
```

#### 專案虛擬環境版本
還有一個方法是用專案與虛擬環境，這個方法我認為更好，因為更乾淨，可以達到內部改變不干擾其他。

可以從以下指令開始:
```bash
mkdir my_project
cd my_project
uv init
```
建立一個資料夾，然後進入資料夾，最後初始化專案。

已存在專案目錄，也可以先進去後直接`uv init`。

如果直接執行 `uv init`，uv 會把專案初始化在「目前所在的資料夾」。因此如果你希望建立一個新的專案資料夾，可以直接使用 `uv init my_project`。

接下來我們要進入專案目錄，如果還在專案目錄外的話，記得`cd`進去。

然後初始化虛擬環境，簡單來說，就是一個獨立的python運行環境，不受外部python全域環境引響，也不引響外部全域環境，主要隔離的是**Python 套件與專案依賴**，不是把整台電腦完全隔離。
```bash
uv venv --python (版本號)
```
> 如果沒寫版本號，就會自動使用 uv 管理的 Python

接下來輸入以下指令啟用(CMD)
```bash
.venv\Scripts\activate.bat
```
PowerShell
```bash
.venv\Scripts\activate
```
Mac/Linux
```bash
source .venv/bin/activate
```
若啟用成功，你將會看到終端機前面出現`(.venv)` 的字樣

要退出則輸入
```bash
deactivate
```

在虛擬環境中`(.venv)`，可以照常用運行指令`uv run main.py`。並且更容易去管理一個專案。
