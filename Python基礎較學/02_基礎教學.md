## 輸入輸出

就是在執行終端頁面讀取或輸出
考試通常用這個傳入資料和回傳答案
可以用來檢查錯誤

- **輸出**
```python
# 列印單一變數與字串
print("Hello World")
```
後面介紹變數時會補充更多用法

- **輸入**
```python
name = input("要在終端顯示的文字")
```

## 資料型別

電腦會用不同型別來儲存不同種類的資料
每個型別都有一些自己的特殊方法，不能混用
所以必須要拆為多種型別
常見型別有:

`int`: 32位元整數(約10^9)
`long long`: 64位元整數(約10^18)

`float`: 單精度浮點數(小數)
`double`: 雙精度浮點數(小數)

`bool`: 是或非(`true `or `false`)

`char`: 字元(一個字符，本質是整數)，用''代表為string
`string:` 字串(很多`char`)，用""代表為string

`array`: 多個同類型資料組成的列表，透過index存取

```python
print(type(num_str))  # <class 'str'> 
print(type(num_int))  # <class 'int'> 
print(type(num_float))  # <class 'float'>
```

## 變數

透過宣告變數，在一個空間儲存一個資料
變數常見的用途包括： 
- 暫存與重複使用資料 
- 保存程式執行過程中的資料與狀態 
- 提高程式碼的可讀性 
- 保存複雜運算的中間結果 
- 接收使用者輸入或其他外部資料


#### **變數的輸出**

```python
# 宣告變數
name = "Alice"
age = 25

# 列印變數（自動以空格分隔)
print("Name:", name, "Age:", age)
# 輸出: Name: Alice Age: 25

# 或是用f可以在大括號裡放變數
print(f"Hello, {name}!")
# 輸出Hello, Alice
```

#### **型別轉換**

因為不同資料型別不能混用
做運算時經常需要手動轉型
最常見的像是輸入時預設為字串，需要轉為數字

```python
num_str = "100" 
num_int = int(num_str) # 字串轉整數: 100
num_float = float(num_str) # 字串轉浮點數: 100.0

age = 25
age_str = str(age) # 整數轉字串: "25"
```

## 運算子

對一個資料執行特定的操作或計算

- **算術運算子**

| **運算子** | **說明**          | **範例**   | **結果** |
| ------- | --------------- | -------- | ------ |
| `+`     | 加法              | `7 + 3`  | `10`   |
| `-`     | 減法              | `7 - 3`  | `4`    |
| `*`     | 乘法              | `7 * 3`  | `21`   |
| `/`     | 除法（結果為浮點數）      | `7 / 2`  | `3.5`  |
| `//`    | 整除（只取整數商數，捨去小數） | `7 // 2` | `3`    |
| `%`     | 取餘數（Modulus）    | `7 % 3`  | `1`    |
| `**`    | 次方（Exponent）    | `2 ** 3` | `8`    |

- **比較運算子**

比較兩邊的值，會回傳`bool`，常用於 `if` 條件判斷

| **運算子** | **說明** | **範例**   | **結果**  |
| ------- | ------ | -------- | ------- |
| `==`    | 等於     | `5 == 5` | `True`  |
| `!=`    | 不等於    | `5 != 3` | `True`  |
| `>`     | 大於     | `5 > 3`  | `True`  |
| `<`     | 小於     | `5 < 3`  | `False` |
| `>=`    | 大於或等於  | `5 >= 5` | `True`  |
| `<=`    | 小於或等於  | `4 <= 3` | `False` |

- **邏輯運算子**

| **運算子** | **說明**                           | **範例**                | **結果**  |
| ------- | -------------------------------- | --------------------- | ------- |
| `and`   | 兩邊都為 True 才回傳 True               | `(5 > 3) and (2 > 1)` | `True`  |
| `or`    | 只要有一邊為 True 就回傳 True             | `(5 > 3) or (2 < 1)`  | `True`  |
| `not`   | 反轉布林值（True 變 False，False 變 True） | `not (5 > 3)`         | `False` |

- **位元運算子** 

| **運算子** | **說明**  |
| ------- | ------- |
| `&`     | **AND** |
| \|      | **OR**  |
| `^`     | **XOR** |
| `~`     | **NOT** |
| `<<`    | 左移      |
| `>>`    | 右移      |
