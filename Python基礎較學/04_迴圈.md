如果要輸出三次`hi`，很簡單
```python
print("hi")
print("hi")
print("hi")
```
但如果要輸出10000次，或是根據輸入次數呢?
那就需要使用**迴圈**了
迴圈能夠根據指定**次數**或是指定**條件**重複執行
主要分成`for`和 `while`

# for

根據指定**次數**來重複執行
`python`預設是**左閉右開**區間
```python
for i in range(3):
	print(i)
# 輸出:
# 0
# 1
# 2

for i in range(1,3):
	print(i)
# 輸出:
# 1
# 2
```


# while

根據條件決定是否重複
```python
i = 0
while i < 3:
	print(i)
	i += 1
# 輸出:
# 0
# 1
# 2
```

# 迴圈控制

- `break` 彈出當前迴圈
- `continue`跳過當前迴圈的後續部分，並繼續執行下一次循環
```python
for i in range(1, 6):
    if i == 3:
        continue  # 跳過 3
    if i == 5:
        break     # 遇到 5 終止迴圈
    print(i)
# 輸出：1, 2, 4
```
