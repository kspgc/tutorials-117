
# 簡述
本章將講述Python基礎語法-if - else -elif 與怎麼用最好。

在程式中，一個決策是由多個是與否決定的，那我們要怎麼讓程式做決策呢? 
這也是許多「反應式系統」最基礎的組成方式之一：**觀察狀態 → 判斷條件 → 執行行動**。

# 教學
先來理解幾個基本的東西:
- **表達式 (Expression)**：**任何可以被評估出一個結果/值的程式碼單位**。
    - 例如：字面值 `"Hello"`、變數 `score`、算術運算 `a + b`、比較運算 `score >= 60`、或是回傳值的函數調用 `len("hi")`。
    
- **陳述式 (Statement)**：**執行某個動作或指令的完整語法結構**。
    - 例如：變數指派 `x = 10`、`if` 判斷區塊、`for` 迴圈等，陳述式本身不具備「一個值」的概念。

>補充知識：有些程式語言的陳述式很多(例如 C++)，有些語言則是「萬物皆表達式」(例如 Rust)。

簡單來說：Expression 通常用來產生或取得一個值，而 Statement 則負責描述程式要執行的動作或控制流程。而這個區分在 Python 中很重要，之後學習函式、迴圈與更進階的語法時會經常遇到。

你可以將 `if - elif - else` 語法直觀地理解為：**「如果...那麼... 否則如果...那麼... 否則...」**

#### 1. 基礎程式碼範例
```python
# 範例一：簡單的雙向判斷 
if is_passed(): 
	print("有及格") 
else: 
	print("不及格") 
	
# 範例二：單向判斷 
if is_rain(): 
	player.bring(Tools.umbrella)
```

#### 2. 完整語法結構
```python
if 條件表達式 A:
    # 當「條件 A 成立」時執行的陳述式/表達式
    ...
elif 條件表達式 B:
    # 當「條件 A 不成立，但條件 B 成立」時執行的內容
    ...
elif 條件表達式 C:
    # 當「條件 A、B 都不成立，但條件 C 成立」時執行的內容
    ...
else:
    # 當以上「所有條件都不成立」時執行的內容
    ...
```
> **縮排 (Indentation) 警告**：Python 非常重視縮排（通常使用 4 個空白）。在 `if / elif / else` 下方縮排的程式碼會形成該條件的**程式區塊 (code block)**，只有該條件被選中時才會執行。

#### 實際使用範例與終端機模擬

將以下程式碼寫入 `main.py`：
```python
# 1. 取得使用者輸入並存入變數(input 預設讀取為字串 str)
name = input("請輸入你的名字：")
score_input = input("請輸入你的考試分數：")

# 2. 將字串轉為整數(int)，方便進行數值比較
score = int(score_input)

result_text = ""
# 3. 使用條件判斷(if - else)做決策
if score >= 60:
    result_text = "及格"
else:
    result_text = "不及格"
    
rating_text = ""
if score >= 90:
    rating_text = "A"
elif score >= 80:
    rating_text = "B"
elif score >= 70:
    rating_text = "C"
else:
    rating_text = "D"

# 4. 格式化輸出結果
print(f"{name} 你好!你的成績是 {score} 分，結果為: {result_text}，評級: {rating_text}。")
```

#### 怎麼用最好？最佳實踐技巧

1. **避免過深的多重巢狀判斷 (Nested If)** 儘量不要寫超過 3 層的 `if` 裡面包 `if`，可以利用 **守衛語句 (Guard Clauses)** 或邏輯運算子 (`and` / `or`) 來簡化判斷。

### 進階拓展：其他分支控制方式

有些情況下，除了 `if-elif-else`，還可以使用 `match-case` 或 Mapping，讓程式碼更符合問題本身的結構。

#### 1. 結構化模式配對：`match - case` 語句

如果你使用的是 Python 3.10 或更新的版本，當遇到**多重固定值的條件檢查**時，使用 `match - case` 會比寫一長串 `elif` 更清晰易讀。

```python
status_code = 404

match status_code:
    case 200:
        print("請求成功")
    case 404:
        print("找不到頁面")
    case 500:
        print("伺服器內部錯誤")
    case _:
        print("未知狀態碼")
```

####  2. Mapping (字典) 控制法

```python
role_permissions = {
    "admin": "權限：全系統讀寫與刪除",
    "editor": "權限：內容編輯與發布",
    "guest": "權限：僅供檢視",
}

user_role = input("輸入身份角色：")

permission_message = role_permissions.get(user_role, "權限：無權存取此系統")
print(permission_message)
```
> Mapping 控制的核心思想是**「用尋找資料取代執行邏輯判斷」**。當你的條件非常多且屬於固定對映時，利用字典能讓程式碼變得非常乾淨，且新增對映項目時，不需要增加新的 `if` 分支。

#### 3. 搭配枚舉
```python
from enum import Enum

class UserRole(Enum):
    ADMIN = "admin"
    EDITOR = "editor"
    GUEST = "guest"

user_role = UserRole.ADMIN

match user_role:
    case UserRole.ADMIN:
        print("權限：全系統讀寫與刪除")
    case UserRole.EDITOR:
        print("權限：內容編輯與發布")
    case UserRole.GUEST:
        print("權限：僅供檢視")
```
> 使用枚舉的優點有很多，例如防止打錯字、有IDE提示、型別檢查、自動補全等功能，讓管理更方便。
